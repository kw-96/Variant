# Variant

一个现代化的项目模板，支持快速开发和部署。

## 项目特性

- 🚀 现代化的开发环境
- 📦 模块化的项目结构
- 🔧 完善的开发工具配置
- 📚 详细的文档说明

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建项目

```bash
npm run build
```

## 项目结构

```
Variant/
├── src/                 # 源代码目录
├── docs/                # 文档目录
├── tests/               # 测试文件
├── logs/                # 日志文件
└── README.md           # 项目说明
```
